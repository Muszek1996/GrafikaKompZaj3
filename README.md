# GrafikaKompZaj3

Computer graphics class exercise 3 (C#, Windows Forms, .NET Framework 4.6.1). `MojaBiblioteka.cs` defines a 2D point class (`Punkt`) with vector operators and a line class (`Prosta`), both with GDI+ drawing helpers. The form has a PictureBox and a button whose handler is still empty.

## Build & run
Open `GrafikaKompZaj3.sln` in Visual Studio and run.
